LLD 測試資料分析報告　DIR0(9) · nA

DIR0(9) 三方比較：Gen1 程式調整前 vs. Gen1 程式調整後 vs. Gen2

比較 Gen1_1003 測試程式調整前 (Before) / 調整後 (After)，與 Gen2_2101 三組資料在 DIR0(9) 測項上的量測分佈、各 Site# 差異與誤差統計。統計基準為 Bin#=1（整體 Pass）之量測值。

Gen1_1003_before（調整前） Gen1_1003_After（調整後） Gen2_2101

資料來源與方法

Bin#=1 Pass Only　用於分佈、均值/標準差、差異、箱型圖與誤差統計等章節  ·  全部 Bin（含 Fail）　僅用於「Fail Rate」章節的 Total 與 Bin#9 計數

資料範圍
每組 10 個 Lot，共取 Bin#=1（Pass）量測值進行統計
欄位定位
DIR0(9) 於三組測試程式中皆位於同一資料欄位（第 9 項測試，單位 nA），已逐檔驗證一致
Site 定義
8-Site 平行測試（Site# 0–7），各 Site 分別統計以檢視站別差異

整體分佈：直方圖

Bin#=1 Pass Only

各組量測值以 2 nA 為區間，統計佔各組總樣本數的百分比，方便在樣本數不同的情況下比較分佈形狀。滑鼠移到線上的點可看到數值。

整體分佈：箱型圖

Bin#=1 Pass Only

箱體為 Q1–Q3（IQR），中線為中位數，菱形為平均值，鬚線延伸至 1.5×IQR 範圍內的最遠資料點；虛線標示測試上限 50 nA。

各 Site# 統計與差異

Bin#=1 Pass Only

Mean/Std 為各組於該 Site 的平均值與標準差；Diff 為後者減前者，括號內為變化百分比。紅字表示數值上升，綠字表示數值下降。

DIR0(9) 不良 (Bin#9) 數量與 Fail Rate

全部 Bin（含 Fail）

Bin#9 為量測值超出 DIR0(9) 規格上限（50 nA）所判定的不良 Bin，已逐筆驗證該 Bin 下的量測值皆 > 50 nA。Total 為該組全部受測顆數（含 Pass 與各項 Fail），Fail Rate = Bin#9 顆數 / Total。

各 Site# 分佈：箱型圖

Bin#=1 Pass Only

每格為一個 Site，三個箱型由左至右依序為 Before／After／Gen2，縱軸統一為 0–50 nA（測試上限）。

誤差值統計（跨 Site 差異分布）

Bin#=1 Pass Only

以各 Site 平均值差異為樣本，計算三組比較（Before→After／After→Gen2／Before→Gen2）的誤差統計指標。

LLD 測試資料分析報告　VF1 · mV

VF1 三方比較：Gen1 程式調整前 vs. Gen1 程式調整後 vs. Gen2

承接前段分析，比較同三組資料在 VF1（正向壓降量測，單位 mV）上的量測分佈、各 Site# 差異與 Fail Rate。注意：VF1 在測試程式中的測項編號因版本不同而不同——Gen1_1003_After 全數為 VF1(14)；Gen1_1003_before 內同時存在 VF1(14) 與 VF1(17) 兩種版本（同一批資料混用了不同版本的測試程式）；Gen2_2101 全數為 VF1(17)。已依每個檔案各自的欄位與測項編號動態解析，確保取值與 Fail 判定正確。規格上下限三組一致，皆為 240–320 mV。統計基準同樣為 Bin#=1（整體 Pass）。

整體分佈：直方圖

Bin#=1 Pass Only

各組量測值以 2 mV 為區間，統計佔各組總樣本數的百分比。

整體分佈：箱型圖

Bin#=1 Pass Only

綠色陰影帶為三組共通的規格範圍（240–320 mV）；菱形為平均值。

各 Site# 統計與差異

Bin#=1 Pass Only

VF1 不良數量與 Fail Rate

全部 Bin（含 Fail）

不良判定：該筆記錄之 Bin# 等於該檔案對應的 VF1 測項編號（14 或 17，視版本而定），且已逐筆驗證量測值皆落在規格範圍（240–320 mV）之外。Total 為該組全部受測顆數，Fail Rate = 不良顆數 / Total。

誤差值統計（跨 Site 差異分布）

Bin#=1 Pass Only

以各 Site 平均值差異為樣本，計算三組比較的誤差統計指標。
