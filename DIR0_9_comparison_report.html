資料來源與方法

Bin#=1 Pass Only　用於分佈、均值/標準差、差異、箱型圖與誤差統計等章節  ·  全部 Bin（含 Fail）　僅用於「Fail Rate」章節的 Total 與 Bin#9 計數

資料範圍
每組 10 個 Lot，共取 Bin#=1（Pass）量測值進行統計
欄位定位
DIR0(9) 於三組測試程式中皆位於同一資料欄位（第 9 項測試，單位 nA），已逐檔驗證一致
Site 定義
8-Site 平行測試（Site# 0–7），各 Site 分別統計以檢視站別差異

整體分佈：直方圖

Bin#=1 Pass Only

各組量測值以 2 nA 為區間，統計佔各組總樣本數的百分比，方便在樣本數不同的情況下比較分佈形狀。滑鼠移到線上的點可看到數值。

整體分佈：箱型圖

Bin#=1 Pass Only

箱體為 Q1–Q3（IQR），中線為中位數，菱形為平均值，鬚線延伸至 1.5×IQR 範圍內的最遠資料點；虛線標示測試上限 50 nA。

各 Site# 統計與差異

Bin#=1 Pass Only

Mean/Std 為各組於該 Site 的平均值與標準差；Diff 為後者減前者，括號內為變化百分比。紅字表示數值上升，綠字表示數值下降。

DIR0(9) 不良 (Bin#9) 數量與 Fail Rate

全部 Bin（含 Fail）

Bin#9 為量測值超出 DIR0(9) 規格上限（50 nA）所判定的不良 Bin，已逐筆驗證該 Bin 下的量測值皆 > 50 nA。Total 為該組全部受測顆數（含 Pass 與各項 Fail），Fail Rate = Bin#9 顆數 / Total。

各 Site# 分佈：箱型圖

Bin#=1 Pass Only

每格為一個 Site，三個箱型由左至右依序為 Before／After／Gen2，縱軸統一為 0–50 nA（測試上限）。

誤差值統計（跨 Site 差異分布）

Bin#=1 Pass Only

以各 Site 平均值差異為樣本，計算三組比較（Before→After／After→Gen2／Before→Gen2）的誤差統計指標。
